# Penetration icons

The penetration upgrade uses two 64x64 RGBA textures:

| Texture | Material | Use |
| --- | --- | --- |
| `penetration-ammo.png` | `ui_penetration_ammo` | Sniper penetration purchase button beside the primary weapon. |
| `wall-impact.png` | `ui_wall_impact` | Owned-upgrade marker in the loadout panel. |

Matching TGA files are inputs for the CoD4 material converter. `source/` contains the original artwork, and `master/` contains the full-resolution icons. `asset-manifest.json` lists texture dimensions, alpha ranges and SHA-256 hashes.
